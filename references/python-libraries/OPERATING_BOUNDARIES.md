# Dependency knowledge boundaries

Status: working guidance subordinate to root AGENTS.md.

Public documentation describes upstream APIs, not the installed managed-client versions. Discover approved versions read-only before making an executed claim. No library seed or matching method name guarantees cross-version identical results or SAS equivalence.

Faker does not certify anonymization. Do not place restricted or real records in this public shelf. Preserve schemas, ordering, integer ranges, date and timezone policy, missing tags, and numerical tolerances when handing data between engines. A working Parquet reader is not a lossless SAS-metadata converter.

No installation, package upgrade, DuckDB extension, remote source access, modified KB stamp, new MCP tool or CI gate is implicitly authorized. Future original Python software requires the repository's separate licensing decision.
