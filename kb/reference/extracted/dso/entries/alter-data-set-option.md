ALTER= Data Set Option
Assigns an ALTER= password to a SAS file that prevents users from replacing or deleting the file, and
enables access to a read- and write-protected file.

Valid in:          DATA step and PROC steps
Category:          Data Set Control
Restriction:       Use in the Compute Server, but not in CAS.
