WHEREUP= Data Set Option
Specifies whether to evaluate new observations and modified observations against a WHERE
expression.

Valid in:         DATA step and PROC steps
Category:         Observation Control
Restriction:      Use in the Compute Server, but not in CAS.




                  Syntax
                  WHEREUP=NO | YES


                  Syntax Description
                  NO
                    does not evaluate added observations and modified observations against a
                    WHERE expression.
