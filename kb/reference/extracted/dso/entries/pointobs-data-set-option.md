POINTOBS= Data Set Option
Specifies whether SAS creates compressed data sets whose observations can be randomly accessed
or sequentially accessed.

Valid in:         DATA step and PROC steps
Category:         Observation Control
Restrictions:     Use in the Compute Server, but not in CAS.
                  POINTOBS= is effective only when creating a compressed data set. Otherwise, it is
                  ignored.
